# 首次接入与个人背景

新用户工作区默认系统实际桌面下的 DSH-Study，已有产品名称或用户指定目录优先。不要用这项约定改动已有 DSH 安装、凭证或日志位置。调用者仍在请求 cwd 中提供核验后的实际工作区路径。

初次接入或明确要求刷新时，可使用已安装的 dsh-context-onboarding Skill 从授权来源整理本人、学校与必要工作习惯，生成个人 Skill。日常派工直接使用已整理版本，避免每轮重扫历史。个人资料属于对应 profile，不能混入通用 Skill 包或另一用户的会话。

当前 dsh_dialogue.py 不会自动发现或加载个人 Skill。调用 AI 根据任务读取已选 profile，写 context-used.md（profile ID/版本、所选事实及出处、必要片段、未知项），放进 source_files，再和当前任务一起提交。现有输入快照及 effective_prompt 可以核对实际注入内容；不能只把远端不可读的路径交给模型。

本轮涉及个性化任务时，另行核对背景来源、主体、时效与实际输入。来源不全标 partial；学校或身份冲突标待澄清；实际派工和回答未核对时，不能宣称个人背景已正确使用。用户修正后增量更新版本，不把本轮模型的推测自动写成用户事实。切换用户需要切换 profile 和 DSH 会话。

这是 Skill 工作流扩展，尚无 App 的自动历史导入、账户路由和背景健康汇总界面。脚本已有 health 只验证运行及连接健康，不包含上述个人背景判定。

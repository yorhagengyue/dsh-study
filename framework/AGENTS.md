# 学习工作区

这里是学习系统的工作区。给 Agent 的开场（宪法 `FRAMEWORK.md` + 状态 + 槽位 + 机器 + 工程）由 `dsh-study-framework` 插件渲染到 `$DSH_HOME/AGENTS.md`，DSH 每个新会话第一步自动读到，本文件不再提供背景。

要看规则读 `FRAMEWORK.md`，要看档位读 `MANIFEST.md`，细则在 `protocols/`。旧的 v0.3 入口（指向 `connection/context/BRIEF.md`）已存档在 `connection/archive/codex-skill-v0.3/workspace.AGENTS.v0.3.md`，不再作为任何会话的背景。

## 产品阶段（写死）

整个工程分四段，先后固定：**连接 → 整理 → 展示 → UI**。

当前在第一段**连接**：把用户、入口 Agent、DSH、资料和记录连通，让"用户一句话，结果出现在眼前"这件事可靠、可追溯、够快。这一段的完成标准：

- 用户发出到看见完整结果，简单任务半分钟内；复杂任务如实报时长，不用其中一段冒充全程。
- 每轮的原话、整理后的目标、实际发送内容、完整输出、工具读取、耗时和验收都能回溯。
- 槽位靠谈话和扫描填起来，来源可追溯；框架健康能报出空了几个、抽屉里等几条。
- Windows 和 macOS 都能跑，写死层两台机器一字不差。

已知限制（产品级，随版本更新）：
- 只用 Markdown，不做界面，不自动开窗口。
- 云端对话历史没有本地文件的不接入。
- PDF、Word 等格式只提供原件，语义解析后续阶段做。
- 整理、展示、UI 三段未开始；提到未来方向不等于已经开工。

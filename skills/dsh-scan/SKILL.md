# dsh-scan · 全扫，从头到尾

一次全扫 = **跑、读、反思、反馈**四步，缺一步不算扫完。耿越 2026-09-16 定：全扫的意义是理解用户，不是数文件；扫完没有反思等于没扫。反思的收件人不只是用户，也是这套系统自己（以后的入口和 DSH）。规则在工作区 `protocols/DISCOVERY.md`（范围、排除、禁区、预算、第 8 节反思）。

**本 skill 目录 = 这个 SKILL.md 所在目录**（Codex `~/.codex/skills/dsh-scan/`，Claude Code `~/.claude/skills/dsh-scan/`，两份一样）。命令用 `node` 和绝对路径，文件都是 UTF-8。配置 `connection.local.json` 在本目录，旧安装在旁边 `dsh-dialogue/` 里，脚本自己会找，不用传。

## 1. 跑（程序，几秒，不用模型）

```
node <本 skill 目录>/app/run.mjs
```

它做四件事：跑 `scan.mjs`（只列文件名，不读内容，禁区只登记）；把 `connection/context/SCAN-<日期>.md` 压成一页摘要打印出来；在 `<工作区>/connection/entry/SCAN-<日期>-反思.md` 生成骨架（已有就不动）；最后打印一段 JSON。安装器装完已经扫过时（`connection/context/` 里有近 7 天的 `SCAN-<日期>.md`）加 `--no-scan`，只做后三件。

**退出码 2，或摘要开头有「⚠ 被权限拦住」**：跑脚本的这个工具没有全盘权限，结果不算。不要说扫完了，对用户只说一句："扫描被权限拦住了，请把我关掉再打开一次，然后随便说一句话。"（安装器已经把权限设好，重开才生效；Mac 上还要在系统设置里给它"文件与文件夹"权限。）重开后从第 1 步再来。

## 2. 读（你自己，不派出去、不派子代理）

读第 1 步打印的摘要，不用打开几十 KB 的汇总；要看细节再开 `SCAN-<日期>.md` 的对应节。读的时候回答骨架里的五个问题，最要紧的是第一个：这个人是谁、在做什么、怎么组织自己的东西。用候选来源、目录结构、课件和笔记的分布说话，不列文件。**从积极的一面开始；量他的尺度是层级不是数量。** 私密目录（`.dsh-private`、聊天软件、日记）只看存在不看内容，写的时候只写模式，标【含私密】。

## 3. 写反思（把骨架填满）

填 `connection/entry/SCAN-<日期>-反思.md` 的五节，一节三到五句；"写的人"写实际的工具名；删掉所有「（待填」。然后

```
node <本 skill 目录>/app/run.mjs check
```

它报 `ok: true` 才算写完；报缺哪节就补哪节。这份反思推到记录仓，给维护者、下一轮的入口和以后的 DSH 看。

## 4. 反馈（对用户说）

按 `protocols/DISCOVERY.md` 第 8 节「摆坐标」说：三到五句，读到了什么、哪些看不见、你从中看到他是谁；然后**只问一个问题**。不发清单、不堆数字、不解释方法。说出去的原话贴进反思第 5 节。

## 5. 回传

```
node <旁边 dsh-dialogue 目录>/app/sync-records.mjs --quiet
```

`connection/entry/` 和扫描汇总一起推到记录仓；完整清单不推。没配置回传时这条命令什么都不做。

## 永远不做

- 不读禁区、不读私密内容、不把清单贴给用户。
- 不让 DSH 扫电脑；DSH 读的是这份汇总和这份反思。
- 不因为"上次扫过"跳过反思：有 SCAN 没反思就补，`check` 说了算。
- 权限被拦时不说扫完了。

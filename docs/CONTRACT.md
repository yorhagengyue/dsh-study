# 资料输入与输出合约

本项目是耿越的第一个资料输入插件。输入插件连接来源，维护可追溯的缓存和读取接口；知识整理、AI 总结、学生 profile 与解释展示属于后续独立模块。

## 输入

来源登记在项目根 `sources.local.json`，按稳定的 `source_id` 隔离缓存。学校名和课程号都是配置数据，不表示学习者学籍。`sources.example.json` 提供无秘密示例。

- Canvas：项目根 `.env` 内的 HTTPS 地址与 API token，及选定的课程 ID。插件只进行资料 GET；不访问成绩、提交记录，不答题、签到或提交。
- 本地文件：配置允许导入的目录与课程名称。Agent 传来源 ID，不能借导入接口指定任意文件系统路径。仓库的合成示例可实际导入，真实个人课件放本机配置目录。
- 本地内部 API：仅监听 loopback，所有资料操作需要项目根 `.env` 中的 `STUDY_API_TOKEN`。DSH 插件在本机读取凭证；工具参数、schema 与输出不包含凭证。

首版支持 Canvas 与本地文件。SMU/Brightspace adapter 尚未实现；本轮没有读取 Cookie、登录浏览器或验证 SMU 会话。

## 输出

目录保留来源、课程、模块/资源身份、原页入口、获取/更新时间、变更与可用性状态。列表被 403/404 拒绝不表示课程没有资料；同步沿合法的模块、首页和正文链接继续读取单项，仍失败时保留旧副本与错误。

读取结果必须区分三件事：

| 表示 | 已提供内容 | 下游可做什么 |
|---|---|---|
| Canvas HTML 正文 | 净化 HTML 与对应文本 | 阅读原文，并保留原页与获取时间 |
| 可可靠解码的 UTF-8 文本文件 | 文件字节与文本片段 | 按返回位置继续读取 |
| PDF、Word、图片等二进制文件 | 限长字节/base64、类型、摘要、偏移与续读位置 | 交给指定解析器，未完成语义抽取 |

“原件已下载”只证明字节已缓存，不证明模型可以阅读全部内容，更不表示模型已经理解。该插件不生成 AI 摘要。具体 `representation`、`text_available`、`extraction_status` 等字段以 [后端 API](BACKEND.md) 为准。

文件读取使用 byte offset；HTML 文本没有可靠的 PDF 页码或版面定位，因此不伪造页号。需要页码/段落/版面定位的文档解析器应在后续模块中返回这些信息。旧副本、权限失败、缺失、外链、尚需解析分别传给调用方，不把它们合并为成功。

## DSH 调用

原生工具覆盖 `sources → courses → refresh/import_local → status → catalog → read`。刷新和导入返回任务身份，调用方通过 status 确认完成与部分失败；接受任务不等于资料已经可读。目录返回的 `source_id`、`course_id`、`resource_id` 是后续读取的参数。

本文规定数据边界；本机真实验证的来源、数量、受限项以及 DSH 实际调用证据单独记录在 `VALIDATION.md`，不把受控测试当作远端资料已更新的证明。

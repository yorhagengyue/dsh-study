# 短目录连接调整计划（2026-09-12）

用户决定：当前只做连接，文档提供目录入口，DSH 按需要读取原文。当前目录、任务、输出、指标与验收使用 Markdown；没有新的明确要求，不制作或打开 Study 页面。

补充：不追求极端简短。简单稳定的信息可以在 BRIEF.md 直接叙述完整，保留必要来源；每轮传简要背景与目录指针。长篇材料和复杂细节再按需读取，避免再次生成和注入整套事实档案。

1. 自动发现已有规则及其直接关联的个人、学校文档，生成本机 INDEX.md。目录只保存标题、路径、用途与来源 ID；原文留在原位置，不抽取整套个人事实。缺失、排除、停用与覆盖范围另存 Markdown。
2. Codex 通过原生 Cordis 插件发出短目标和目录入口。DSH 自行查目录、选择来源和分段读取，读到的内容保留路径、版本哈希与行号。源文档是资料，不授予新权限。
3. 输入、完整文本输出、公开工具调用、时间、用量与独立验收保存为 Markdown。移除自建 Study 页面与自动开窗；保留官方 DSH 原生会话能力。

验收：在 Windows 真实安装、启动、API 派工、按需读取、回答并实读结果；在 Mac 验证相同路径。检查原文未被提前注入，原生工具读取可追溯，安装及重启不丢历史，凭证不进入目录与日志。两端的实际计时分别记录，API 收到完整输出不冒充用户看到输出。

兼容：旧 v0.2 事实档案和记录保持原样，不作为新任务默认背景。原生 DSH 的配置、认证和通信格式遵循其接口；本插件新生成的目录、对话证据和报告为 Markdown。

这是初期版本。目录发现、检索方式、输出、计时和质量评估都允许后续改进，不把这次实现固定成最终架构。
